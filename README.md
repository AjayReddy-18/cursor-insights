# Cursor Stats

Display your current Cursor monthly usage directly in the status bar.

## Features

- 💰 Shows current monthly usage
- 🔄 Auto refresh every 60 seconds
- 🔐 Securely stores your WorkosCursorSessionToken using VS Code Secret Storage
- 🖱 Click the status bar to refresh manually

## Setup

1. Install the extension.
2. Click **Connect Cursor**.
3. Paste your WorkosCursorSessionToken.
4. Your usage will appear in the status bar.

## Status Bar

Example:

⚡ $18.76 / $200.00

Hover to view:

- Used
- Remaining
- Billing cycle

## Commands

- Cursor Stats: Connect Account
- Cursor Stats: Disconnect Account
- Cursor Stats: Refresh
